# Mini Battle Game

A small Python project created to practice object-oriented programming (OOP).

## Features

* Player and Wizard classes
* Objects and attributes
* Health and level system
* Attack methods
* Damage system
* Leveling up
* Magic system
* Spell casting
* Inheritance
* Method overriding
* `super()`

## What I Practiced

* Classes and objects
* `__init__()`
* Attributes and methods
* Inheritance
* `super()`
* Method overriding
* Modifying object attributes
* Object state
* Basic OOP structure

## Versions

### V1

The original version created while learning the fundamentals of object-oriented programming.

### V2

An improved version with:

* `Wizard` inheriting from `Player`
* `super()` for shared attributes
* Method overriding
* Improved status displays
* A magic system for the Wizard
* Better use of inherited methods
* Cleaner code structure

## How to Run

Make sure Python is installed on your computer.

Run the program with:

V1
python "Mini_Battle_Game_V1.py"

V2
python "Mini_Battle_Game_V2.py"
